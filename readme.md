# E-Commerce Web Application

A full-stack e-commerce web application developed using Java, Spring Boot, Thymeleaf, MySQL, Bootstrap, Cloudinary, and Razorpay.

## Features

- User registration and login
- Admin management
- Merchant product management
- Customer product browsing
- Product search and management
- Shopping cart
- Online payment integration
- Image upload using Cloudinary
- Role-based access

## Technologies Used

- Java
- Spring Boot
- Thymeleaf
- MySQL
- HTML
- CSS
- Bootstrap
- JavaScript
- Cloudinary
- Razorpay
- Maven

## Project Modules

### Admin
- Manage users
- Manage products
- Manage merchants

### Merchant
- Add products
- Update products
- Delete products
- Manage inventory

### Customer
- Register/Login
- Browse products
- Add products to cart
- Place orders
- Make payments

## Database

MySQL is used for storing user, product, order, and other application data.

## How to Run

1. Clone the repository.
2. Open the project in Eclipse/IntelliJ/VS Code.
3. Configure MySQL database.
4. Update application properties.
5. Run the Spring Boot application.
6. Open the application in a browser.
